# ferramentas — Grupo Humanidade

Utilitários avulsos: ferramentas sem dado atrás, HTML estático, servidas por link.
Não têm Cofre nem dono de produto — por isso não moram dentro do Pocket nem do
Painel Comercial.

## Como é servido

GitHub Pages, branch `main`, pasta `/docs`.
Cada utilitário é uma pasta com um `index.html` autossuficiente (fontes e imagens
embutidas, nada de CDN).

| Utilitário | URL |
|---|---|
| Emissor de Recibos | https://humanidade-grupo.github.io/ferramentas/recibos/ |

## Para publicar um utilitário novo

1. `docs/<nome>/index.html`, autossuficiente.
2. Commit e push na `main`.
3. Uma linha na tabela acima.

Nada de segredo no HTML — vale aqui a mesma regra do resto do grupo.

## Histórico

O Emissor de Recibos nasceu em `pocket-nps/docs/recibo/` e veio para cá em
